# Security policy

Please do not disclose vulnerabilities in public issues. Report them privately
through GitHub's **Security > Report a vulnerability** feature for this
repository, including reproduction steps and the affected ChatSpace version.

Never submit passwords, access tokens, service-role keys, database passwords,
Firebase service-account JSON, or Android signing keys in an issue or commit.

Only APKs attached to releases in this repository and signed with the permanent
ChatSpace production certificate should be treated as official builds.
